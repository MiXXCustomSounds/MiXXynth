# MiXXynth — Product Draft (pre-spec)

<!-- Separate from MiXXFX. Do not copy MiXXFX PRODUCT.md claims. -->

## Platform (proposed)

Windows desktop (JUCE VST3 + Standalone). CLAP TBD in spec Q&A.

## Users (proposed)

Producers / sound designers building synth patches in a DAW; preset tweakers to deep FM programmers.

## Purpose (proposed)

A modern FM-forward synth with fast drag-drop modulation and a built-in multi-FX rack for finished sounds without leaving the plugin.

## Capabilities under consideration (no commitment until SPEC sign-off)

- FM engine: op count / algorithms / feedback / key-scaling TBD
- Subtractive extras: filter, envelopes, LFOs, macros TBD
- Modulation: drag-and-drop LFO/Env/Macro -> any knob, depth ring, right-click clear
- Multi-FX rack: synth-tailored (chorus/delay/reverb/distortion/hyper) vs full MiXXFX-style reorder rack TBD
- Polyphony / unison / voice stealing / CPU budget TBD
- Presets: XML vs JSON, factory bank, DAW state + automation TBD
- UI: resizable host-embedded editor, transient values, visualizers TBD
